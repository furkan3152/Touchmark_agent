Governance · STL-H01

Single admin is a critical trust root

Validator/reviewer and escrow fee management are tied to a single address; rotation/recovery policy has not been proven.

Specific fix: Make the admin a multisig or governance contract; add pending admin + ledger-time delay + accept/cancel event flow.

admin.require_auth();
storage.set(PendingAdmin, (next, activate_at));

High
Testing · STL-H03

No property/fuzz and real C-account negative tests

Unit tests verify selected paths; they do not scan the state-space and custom __check_auth behavior.

Specific fix: Fuzz unique review total, deadline, replay, TTL, and SAC conservation invariants; add wrong context/threshold/replay tests with minimal C-account.

review_total == sum(unique_scores)
fee + provider_payout == funded_amount
request.validator is immutable
late submit and complete always fail
Medium
Authentication · STL-M01

SEP-45 Draft auth server missing

C-account web session cannot be activated without a version-pinned challenge/session server.

Specific fix: Keep the feature disabled; set up a separate C-account endpoint with specific SEP commit, nonce/domain/network binding, and replay store.

Medium
Data operations · STL-M02

Missing event retention and ingest SLO evidence

Cursor/dedup exist; provider retention gap, cursor loss, and lag are unproven in a live environment.

Specific fix: Persist the last successful ledger, watermark, and gap list; add backup cursor, lag SLO, retention alarm, and restore drill.

Medium
Release · STL-M03

Public SEP-1 and independent reproducibility missing

Local/chain WASM hash parity with Contract ID exists; published stellar.toml and a second clean environment rebuild record are missing.

Specific fix: Prove that two clean environments produce the same WASM hash; publish only verified endpoints/contract IDs to SEP-1.

Medium
Audit quality · STL-M04

No adjudicated Stellar ground truth

Intent, security, and Stellar-native scores are not the same target; distance to overall score does not prove auditor accuracy. Slash and ELO movement are disabled for this reason.

Specific fix: Create a blind adjudication and appeal-final benchmark corpus for Stellar agent/Soroban/SEP findings.

Low
Supply chain · STL-L01

No SBOM/advisory archive

Pinned SDK, clippy, and pip check are not known vulnerability scans.

Specific fix: Add cargo audit, pip-audit, CycloneDX SBOM, and independent WASM hash results to the immutable release bundle.
