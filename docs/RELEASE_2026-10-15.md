# Evidence workspace release — 15 October 2026

> Historical checkpoint. Current official tiers, deployed contracts and verified pilot evidence are documented in [the official pilot release](OFFICIAL_PILOT_2026-10-15.md). Retained audit limitations still apply unless explicitly resolved there.

## Implemented

- New responsive English workspace with a restrained light interface, custom vector mark, evidence dossier, report tabs, coverage catalogue, pricing and explicit availability states.
- Twenty-four control areas covering intent, code, tool authority, MCP, delegation, memory/RAG, network, privacy, economic controls, runtime failures and Stellar-specific boundaries. Every control displays required evidence; none is declared runtime-verified from a keyword match.
- Structured architecture declarations participate in the input commitment. Explicitly disabled MCP authentication, memory isolation, delegation attenuation and unrestricted egress produce review findings.
- Optional public AI second opinion with per-review consent, operator enablement, bounded source, best-effort secret redaction, valid source-location checks and no ability to override static results.
- Browser-local exact-byte report fingerprint verification; no upload to verify a downloaded file.
- Policy simulation API/UI and opt-in SQLite enforcement SDK: exact policy/action approval, strict integer amounts, replay prevention, concurrent budget reservations, expiry/network/version/delegation checks and persistent emergency stop.
- Registry validation requests bind to the original version, metadata and endpoint commitments; response rejects a changed or inactive version.
- New non-transferable audit credential contract with issuer authorization, report binding, expiry, owner/issuer revocation and current-version checks.
- Atomic constructor initialization for fresh registry and escrow deployments, closing the separate-init takeover window.
- Vercel stateless Studio entrypoint, durable Docker/Compose service, GitHub validation workflow, threat model, business model and chapter-oriented Instawards sprint proposal.

## Breaking changes and migration

Registry v0.2 validation record shape changes. Deploy fresh contracts and create a new evidence manifest; do not treat the old testnet registry as v0.2. Constructor parameters are required when deploying registry and escrow. `init` is retained but cannot overwrite constructor-initialized state. The new credential interface is purpose-built and does not claim a standard marketplace NFT interface.

The public Vercel entrypoint deliberately exposes only stateless routes. Run persistent operator jobs and monitoring on one durable worker with a protected volume; customer multi-tenancy and distributed storage are not implemented.
