                How a touchmark is earned

                i.

                Reads the code, not the claims

                Python, JavaScript and TypeScript are traced from what a request says to what the agent signs, pays or fetches. A declared limit the code does not enforce is reported, never credited.

                ii.

                Asks it the wrong way

                Reworded, split, role-played and planted requests; approval flags the model fills in; a server the requester picks. If only the prompt stops it, it is not stopped.

                iii.

                Stamps what passed

                A Soroban contract issues the credential only for a validated report: bound to its hash, its score of 65 or more, and the version that was tested.
