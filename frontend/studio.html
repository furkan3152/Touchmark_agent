          07

          Good questions. Straight answers.

          What the Studio establishes, and what it does not.

          Can I add any Stellar agent?

          You can submit a public G-account or C-contract address on Testnet or Mainnet, or provide source without a wallet. The address check is read-only. A private agent needs its owner's source or a later authorized runtime test; no service can fully audit hidden behavior from an address alone.

          Does Stellar have an agent key?

          There is no universal agent ID required by this product. Agents may use ordinary Stellar accounts or smart accounts with delegated permissions. We ask for public identifiers only. A private key is authority to act, not evidence of trustworthy behavior.

          What does an audit establish?

          Official reviewers inspect the supplied source and declared boundaries. Authorized runtime plans execute supported Python entry points in isolated microVMs. The dossier keeps source findings, runtime observations, AI hypotheses and chain evidence distinct. Each claim is bound to the evidence actually collected; an untested surface remains an open question.

          Does a credential mean the agent is safe?

          No. It records an issuer's assessment of a specific version. It cannot reveal hidden behavior or guarantee future behavior. Always check the report scope, issuer, version, expiry and revocation state.

          What is available today?

          The workspace checks the available reviewers, providers and official order service on this deployment. Immediate source review works without keys. An enabled official order service saves the consented scope before funding, runs the review and completes Testnet delivery. Private receipts control access to the report; its hash and token record are public. Runtime and AI review keep their separate consent and access requirements. Testnet uses test assets only.

          When should I use the quick test on the home page instead?

          When the agent's code is in a public repository and you want a rules verdict in about a minute, with an optional model review that reads every file and a testnet stamp for a pass. Come to the Studio for private code, uploads, a declaration you are still drafting, chosen reviewers, or a dossier you keep.
